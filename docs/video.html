Read the lesson — text alternative

A neural network learns by adjusting the numbers inside it. This example classifies small, noisy pictures of sevens and ones.

  1. Read an example. A 5-by-7 image provides 35 pixel values. A known label says whether it is a seven or a one.
  2. Make a prediction. Six hidden units combine weighted inputs and biases, then apply sigmoid. An output unit produces a score for the class seven. There are 223 learnable weights and biases.
  3. Measure the error. Binary cross-entropy compares that score with the correct label. For an example labeled seven, a larger score lowers the loss.
  4. Find the gradients. Backpropagation applies the chain rule backward through the computation. It finds how sensitive the loss is to each parameter; the weights have not changed yet.
  5. Take a small step. Gradient descent subtracts the learning rate times the gradient from each parameter. The updated network makes a new prediction.
  6. Practice and check. Repeat across training examples, then evaluate separate held-out data. The plotted curves are measured on this fixed toy dataset; they are not a claim about real handwriting recognition.

The big idea: predictions forward, gradients backward, small updates, repeat. Test whether the learning carries over to new examples.
