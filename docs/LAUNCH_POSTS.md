I made Monamotron, a reusable skill for coding agents that create visual explanations.

The live page is a playable example. To create a new lesson, install the skill in OpenCode, Claude Code, or another compatible agent and give it a topic. The repository includes the instructions, SVG/Canvas runtime, fonts, editable scenes, tests, and real video exports.

The renderer uses one deterministic timeline for stroke reveal, character typing, captions, seeking, and exports. The neural-network example's displayed gradient, update, and learning curves come from a small numerical experiment; selected gradients are checked against finite differences.

It doesn't require an image-generation service for the code-drawn artwork. The host needs coding/browser tools to build and check artifacts. Default video export is WebM; MP4 uses FFmpeg.

## Community Showcase

**Title:** I built Monamotron, an agent skill for illustrated, animated explanations

```text
I wanted AI explanations to feel more like a person teaching at a whiteboard: draw an idea, label it, connect it, and explain the relationship.

Monamotron packages that workflow as a skill. It includes code-made illustrations, progressive drawing and typing, purposeful arrows, images/media, responsive playback, and actual video export.

The current example explains neural-network learning on a chalkboard, using a small tested model for the displayed numbers. A solar-energy sketch is included too.

Demo: https://ibrahim-hero.github.io/monamotron/
Source: https://github.com/ibrahim-hero/monamotron

If this fits your workflow, try it on one topic and tell me where the visual explanation or setup could improve.
```
