# Support

## Questions And Usage Help

Open a GitHub Discussion if Discussions are enabled. Otherwise, open an issue using the question/feature template and include:

- The host and model being used.
- Operating system and Node.js version.
- The prompt or scene that triggered the problem.
- The exact build/check command and complete error output.
- A screenshot or minimal scene JSON when the issue is visual.

## Bugs

Use the bug-report issue form. Please run `npm test` and, when possible, `npm run check:browser` before reporting a renderer or export bug.

## Security

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).
