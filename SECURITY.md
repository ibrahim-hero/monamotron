# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier | No |

## Report A Vulnerability

Use GitHub's **Report a vulnerability** private security-advisory flow for the repository. Do not include exploit details, private files, API keys, or untrusted media samples in a public issue.

Include the affected version, reproduction steps, impact, and any proposed mitigation. Maintainers should acknowledge a complete report within seven days and coordinate disclosure after a fix is available.

## Media Safety

The builder accepts authored local media and rejects unsupported remote dependencies for standalone artifacts. Treat third-party SVG, HTML, scene JSON, and video as untrusted input. Review licenses and content before embedding or publishing them.
