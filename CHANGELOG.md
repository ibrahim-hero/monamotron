# Changelog

All notable project changes are documented here. This project follows semantic versioning.

## [Unreleased]

### Added

- Architecture guide with system diagrams, runtime responsibilities, example data flow, and build/export commands.
- Dedicated demo watch page with chapter navigation, a text alternative, and video downloads.
- Full-speed MP4 demo and animated README preview, with reproducible FFmpeg generation.

- README with guided setup for OpenCode and Claude Code, prompt examples, architecture, and a task-based documentation index.

## [1.0.0] - 2026-11-01

### Added

- Portable `monamotron` skill with model-independent instructions.
- Eight visual directions and five display-font choices.
- Deterministic SVG renderer with progressive drawing and grapheme-aware typing.
- Responsive player with replay, pause, seeking, speed, chapters, transcript, and reduced-motion behavior.
- Standalone HTML builds with embedded fonts and local media.
- SVG, PNG, scene JSON, WebM, and optional FFmpeg MP4 export paths.
- Solar-energy starter scene.
- Featured neural-network chalkboard lesson backed by tested numerical calculations.
- Browser checks for 40 style/font combinations, mobile layout, media, and video decoding.
- GitHub documentation, CI, community files, and release packaging.
